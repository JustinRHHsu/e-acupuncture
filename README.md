# 尬電儀 God Damn IT

你的隨身 AI 中醫師 — 手機優先的 Mobile Web App 概念原型。

## 原型版本

| 版本 | 入口 | 內容 |
| --- | --- | --- |
| 尬電儀 Mobile Web App | [index.html](index.html) | 互動虛擬角色、引導對話、穴位參考圖、個人健康日誌 |
| 手穴導引（另版原型） | [prototypes/hand-guide/index.html](prototypes/hand-guide/index.html) | 可旋轉的 3D 手部模型、左右手與掌背切換、症狀挑選及穴位瀏覽 |

兩個版本共用下方啟動方式。啟動後，主版位於網站根目錄，另版位於 `/prototypes/hand-guide/`。

## 開啟

在此 checkout 內執行 `npm start`，以 HTTP 開啟連接埠 3000。無須安裝套件；需要 Python 3 與 Node.js（語法檢查用）。`npm run check` 檢查 JavaScript 語法。

## 已實作

- 手機單欄版面、底部分頁與安全區適配；桌面以手機寬度呈現。
- 虛擬成年中醫師角色，以 WebGL 變形呈現呼吸、上身擺動、游標／觸控拖曳回應及對話時的輕微動態。輕點角色會回應招呼；可主動開啟瀏覽器語音朗讀（聲音、語言與可用性依裝置而定）。無 WebGL 時顯示 CSS 動畫；支援減少動態偏好。
- 預設問題與自由輸入，示範位置、發生時間、程度、其他感受的引導問答。
- 穴位參考圖：左右手、手掌／手背共四種視圖，八個有名稱、代碼、引線與解剖定位說明的常見經穴。手掌：勞宮 PC8、魚際 LU10、大陵 PC7、神門 HT7；手背：合谷 LI4、三間 LI3、中渚 TE3、後溪 SI3。圖上位置與標籤共用 SVG 座標，避免縮放時錯位；左右手與掌背會分別鏡像。
- 穴位可用觸控、滑鼠或鍵盤選擇並記錄感受。保存的日誌帶有穴位名稱及代碼；左右手、掌背與照片／參考圖的紀錄分開。
- 個人照片上傳、手動標記及程度紀錄；不將示意圖穴位自動套到未校準的照片上。
- 對話摘要與手部紀錄可明確點選保存到此瀏覽器的 localStorage，亦可逐筆刪除。
- 常見急症詞彙會停止示範操作並顯示求助提示。這只是示範規則，不能取代醫療評估或安全分類系統。

## 範圍與限制

這是預設流程原型，沒有呼叫語言模型、醫療知識庫、遠端語音 API 或電子針灸設備。語音使用裝置的 Web Speech API。穴位解剖說明為人工整理的教育參考，圖上點位是示意，尚未經合格中醫師臨床審核或個人手部定位校準，不能作為電刺激操作依據；不根據測點疼痛推斷器官狀況，不產生治療或電刺激處方。

標準經穴與原廠手診圖中的器官反應區是不同分類。本版只顯示上述標準經穴，未將產品反應區混入，也未宣稱經絡名稱代表器官檢測結果。本輪嘗試讀取 WHO 與香港官方中醫資料網站時受到網路政策 403 限制，未完成外部來源逐條核對；正式上線前須完成資料核對、臨床審核及設備適用性確認。

角色目前是可點擊、拖曳與發聲的單張插畫 2D 動畫，**未接入 Live2D Cubism**，不具備眼球、眨眼或嘴型的獨立骨架；語音不等於嘴型同步。正式 Live2D 版本需要有授權的 `.model3.json`、`.moc3`、貼圖與表情／動作檔，以及 Cubism runtime。可用正式模型 adapter 替換 `avatar.js` 中的 `window.doctorAvatar.speak/stop`，並掛載至 `#avatar`。

照片只在分頁記憶體暫存，日誌不保存照片；重新載入後照片與未保存的手部標記會消失。保存的紀錄留在此瀏覽器，清除網站資料即刪除；此版本不是正式病歷系統。字體可選擇性從 Google Fonts 載入，離線時使用系統字體。
